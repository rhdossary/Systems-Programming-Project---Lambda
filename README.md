# Systems-Programming-Project---Lambda
Project Description: This project is a simple Mini Shell implemented using Python.  
The shell allows users to execute basic operating system commands interactively through the terminal.
The project demonstrates important systems programming concepts such as:
- Command execution
- Process handling
- User input parsing
- Error handling
   Features:
- Execute external commands such as:
  - ls
  - pwd
  - echo
- Support built-in commands:
  - cd
  - exit
  - quit
- Display dynamic shell prompt
- Handle invalid commands safely
- Handle keyboard interruptions
